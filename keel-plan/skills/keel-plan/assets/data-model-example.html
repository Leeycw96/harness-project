数据模型设计

订单域

orders · 订单
字段类型中文注释
id «PK»bigint订单编号
order_novarchar(32)订单号
statusvarchar(24)已支付
refund_requested_at [新增]timestamp，可空申请退款时间
1 ───── 0..*一个订单对应多次退款申请
逻辑关联，无数据库外键
refund_requests · 退款申请 [新增]
字段类型中文注释
id «PK»bigint退款申请编号
order_id «关联键»bigint所属订单编号
amountnumeric(12,2)退款金额
reasonvarchar(200)退款原因
SQL · PostgreSQL
ALTER TABLE orders
    ADD COLUMN refund_requested_at timestamp;

CREATE TABLE refund_requests (
    id       bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    order_id bigint NOT NULL,
    amount   numeric(12, 2) NOT NULL CHECK (amount > 0),
    reason   varchar(200) NOT NULL
);

CREATE INDEX idx_refund_requests_order_id
    ON refund_requests (order_id);

商品域

products · 商品
字段类型中文注释
id «PK»bigint商品编号
namevarchar(120)商品名称
subtitle [新增]varchar(120)，可空商品副标题
1 ───── 0..*一个商品对应多个规格
数据库外键
product_skus · 商品规格
字段类型中文注释
id «PK»bigint规格编号
product_id «FK»bigint所属商品编号
spec_namevarchar(80)规格名称
barcode [新增]varchar(32)，可空商品条码
SQL · PostgreSQL
ALTER TABLE products
    ADD COLUMN subtitle varchar(120);

ALTER TABLE product_skus
    ADD COLUMN barcode varchar(32);

COMMENT ON COLUMN products.subtitle IS '商品副标题';
COMMENT ON COLUMN product_skus.barcode IS '商品条码';
