# 库存预占服务

这是测试任务的预设业务要求，目的是评估 Plan、Dev、Fix 产物。用户尚未审阅生成的 HTML。

现有服务可查询商品库存。新增三个功能：

1. 创建预占：按订单、商品和正整数数量预占库存，恰好等于可用库存也允许；不足时拒绝，不能超卖。同一订单重复相同请求返回原结果，不重复占用；不同商品或数量返回冲突。
2. 确认扣减：确认有效预占后扣减账面库存，预占变为已确认；重复确认不重复扣减。取消后的预占不能确认。
3. 取消释放：取消有效预占后恢复可用库存；重复取消不重复释放。已确认预占不能取消。

库存只包含一种整数计量单位，无过期、认证、支付、消息队列或外部系统。查询返回账面库存、预占量和可用量。未知商品或预占返回明确错误，失败不改变库存。

预设技术选择：沿用 Python 标准库 HTTP、SQLite 和 unittest；数据库事务保证并发请求不能超卖，服务重启后数据仍在。三个功能都生成时序图，业务流程总览、状态机和新增表关系图按 Spec 提供。测试确认仅允许推进隔离评估，不表示用户已批准产出的 HTML。
