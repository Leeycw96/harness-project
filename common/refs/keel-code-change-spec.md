# Keel Code Change Spec（S）

## 改造点

- 方案或修复说明的每项为 ``- `真实类/模块或文件`：一句话改动``，不包含逐行实现设计。

正确示例：- `OrderService`：复用现有金额格式化能力处理折扣结果。

- 对象为项目真实类/模块，无此结构则为文件；有歧义的名称带模块或路径限定，新增对象有明确标记。

- 改动按对象归并，覆盖本次必要联动，不含无需修改的对象；列表不展开方法、字段、行号、调用链、代码或步骤，细节位于设计或调查资料。

- 测试文件、用例和命令不属于改造点列表。
