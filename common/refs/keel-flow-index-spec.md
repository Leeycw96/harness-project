# 业务流程文档维护规范（S）

## 业务流程索引

- 默认目录 `.keel/call-chain/`；按共用粒度，每流程一份 `<domain>-<flow>.md`。

- 文档反映实际实现，包含本次外部 HTTP/RPC/MQ/Scheduler/callback 入口、异步推进点、业务状态节点、流转条件、生命周期和状态变更符号的变化。
- 已有流程文档保持当前内容；新增文档仅适用于同一目标由至少两个外部入口推进、初始请求后异步推进、跨阶段生命周期状态流转任一成立的流程。
- 无业务状态机的查询、统计、导出、单步 CRUD、内部调用、DAO、DTO、参数校验不属于索引范围；内部模块的业务状态变化仍属范围。范围不确定时报告包含证据缺口，不能声明无需维护或凭猜测新增文档。

- 含业务目标、开始至终态的业务步骤及：

- 入口目录：步骤、触发类型、仓库相对路径、入口符号、说明。
- 当前业务状态机：名称/值、含义、初/终态、自包含 PlantUML 状态图；无则写不适用。
- 状态流转表：源/目标状态、触发事件、前置条件、业务入口符号、实际状态变更符号、证据路径；标明异步触发，依代码覆盖创建、失败、重试、补偿、终态。

- 状态图、流转表与文字一致，无失效节点、关联边或本期高亮。入口符号与实际执行状态变化的符号分别注明，无类语言用真实模块/函数。普通内部调用栈不展开，实际状态变更位置必留。

## 维护结果

- call-chain-review.md 含 NOOP/UPDATED、检查范围、入口/状态变化证据、已有文档/新建条件判断、更新文件或未更新原因；结论有实际代码依据，未实现的计划目标不属于现状，不确定项有证据缺口说明。
