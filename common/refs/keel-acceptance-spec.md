# 交付验收规范（S）

## 验收报告

- 任务指定目录的 qa-feedback.md 包含 APPROVED 或 REJECTED、指定范围及关联影响的实际检查结果与证据；已有评分记录可引用，避免重复展开。
- 计划中每个功能目标都有完成情况，全部验收条件满足才算完成；实现与补充测试的质量结果对应 `.codex/common/refs/keel-code-quality-spec.md#代码与测试标准`。
- 通过结论有充分证据，标准缺失、要求冲突、阻断项或必需验证缺口有明确说明，不能记通过。
- 报告包含实际验证命令与结果、阻断项、非阻断观察，以及未验证或待现场复验事项。
- 失败说明属于既有问题、环境限制还是本次回归，不将无关失败归入本次改动。
