# 交付验收规范（S）

## 验收报告

- qa-feedback.md 位于任务目录，结论为 APPROVED 或 REJECTED。
- 每个功能目标简述完成情况和关键结果；失败、遗漏或未验证项说明原因与影响。
- 全部验收条件满足才算完成；代码与补充测试符合 `.codex/common/refs/keel-code-quality-spec.md#代码与测试标准`。
- 评分 JSON 只记录目标与检查项的分数；正文不重复逐项明细，不附代码片段、日志或命令清单。
- 验证摘要按检查类型简述结果，无需另存验证日志或整理执行记录。
- 阻断、非阻断观察、未验证和现场缺口明确；验收条件未满足、标准缺失或冲突不能通过，失败区分已有、环境或本次回归。
