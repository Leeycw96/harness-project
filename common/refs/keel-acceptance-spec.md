# 交付验收规范（S）

## 验收报告

- qa-feedback.md 位于任务目录，结论为 APPROVED 或 REJECTED。
- 每个功能目标一项：完成情况、关键结果、证据引用；通过项简述，失败或遗漏项含触发条件、原因与影响。
- 全部验收条件满足才算完成；代码与补充测试符合 `.codex/common/refs/keel-code-quality-spec.md#代码与测试标准`。
- 逐项明细在评分 JSON 和日志中，正文引用，不重复长表、代码行号或命令清单。
- 验证摘要按检查类型归并，含实际命令及结果，或完整记录引用。
- 阻断、非阻断观察、未验证和现场缺口明确；缺必要证据、标准缺失或冲突不能通过，失败区分已有、环境或本次回归。
