# 交付验收规范（S）

## 验收报告

- APPROVED 仅返回简短通过结论、当次评分路径和必要遗留项；qa-feedback.md 可省略，生成时只写概要。
- REJECTED 在任务目录生成 qa-feedback.md，简述阻断项、原因、影响和返修所需信息。
- 全部验收条件满足才算完成；代码与补充测试符合 `.codex/common/refs/keel-code-quality-spec.md#代码与测试标准`。
- 返回消息或报告不附逐项明细、代码、日志或命令清单；必要验证摘要按检查类型简述。
- 阻断、非阻断观察、未验证和现场缺口明确；验收条件未满足、标准缺失或冲突不能通过，失败区分已有、环境或本次回归。
