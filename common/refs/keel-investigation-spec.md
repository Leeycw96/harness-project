# 问题调查（S）

## 调查结论

- 报告简述现象、预期及其依据、原因、影响范围和仍需确认的事项；版本与现场条件仅在影响判断时说明。
- 结论使用“已定位、候选原因、暂未定位”。“已定位”须符合实际情况并能解释本次现象，不以本地复现作为唯一条件，无需附代码或日志存档。

错误示例：代码里有日志语句，就断定本次运行经过该分支；没有日志，就断定事件未发生。

- 未确定结论简述已核实范围和仍不能确定的事项，不把尚未确认的原因写成已排除。

- 多个候选原因说明各自理由与进一步区分的方法；只请求能解决当前不确定事项的必要资料。

- 代码行为验证、诊断能力改造和原场景复验不能互相代替；报告简述已验证结果与现场缺口。
