# 问题调查（S）

## 调查结论

- 报告包含现象、预期及其依据、代码版本、日志来源、现场条件和影响范围。
- 结论使用“已定位、候选原因、暂未定位”。“已定位”有能解释本次现象的证据，不以本地复现作为唯一依据。

错误示例：代码里有日志语句，就断定本次运行经过该分支；没有日志，就断定事件未发生。

- 未确定结论包含已核实范围、支持和反对证据、仍不能确定的事项，不把拿不到证据写成已排除。

- 多个候选原因各有依据和区分它们所需的证据。补充资料需求说明必要关键字或代码位置、时间范围或请求标识、字段及用途。

- 代码行为验证、诊断日志补齐和原场景复验分别记录；报告说明已验证结果与现场缺口，三者不能互相代替。
