# CallChain 文档提交改为可选

用户明确要求移除 CallChain 文档必须提交 Git 的限定。

- Spec 的维护结果只要求文档变化、结论和证据，不要求独立文档提交。
- Agent 仅在任务明确要求时提交，其他工作方式沿用。
- Skill 核对更新文档与报告后记录 UPDATED，完成不依赖提交 SHA。
- `record_call_chain_result` 的第二参数保留为可选提交信息，无提交时记录 null；提供的 SHA 仍须格式有效。

NOOP、按需调度、报告核对、返修与恢复规则保持原样。历史运行记录保留。

验证临时部署中的未提交文档能够完成 UPDATED；检查报告缺失仍阻断、可选提交信息可记录、非法可选信息不改变状态。
