# 接口审阅模板

用户已确认接口 HTML 样例，要求纳入仓库并由 Planner 起草时参考；修改归入 4.0.7。

接口设计仅包含本期变化的 HTTP、RPC 与 SDK 对调用方公开的契约，内部实现方法放执行说明或代码改造点。SDK 使用公开签名标题，参数、返回值及异常按实际协议表达，不强套 HTTP 或 JSON 格式。

HTML 按接口展示签名、入参、出参和必要局部示例；省略失败响应、错误码、异常处理及结果说明。执行所需错误/异常契约在 MD 独立段落保留，以规范约定标签开头，由渲染器在审阅栏目隐藏；下载与快照继续保留源文档。

确认过的 HTML 保存为 `keel-plan/skills/keel-plan/assets/interface-example.html`。接口设计标准引用模板，起草任务同时提供标准与模板路径。正式 HTML 仍由功能 MD 生成，不另外维护第二份契约。

验证覆盖 SDK 签名与共享定义、错误段落隐藏但源文档和下载保留、现有规划契约、临时部署模板一致性及精简检查。
