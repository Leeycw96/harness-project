# 时序图参与方归并

用户已确认将本次时序图参与方按业务模块归并，并将规范和样例一并提供给 Planner；修改归入 4.0.7。

使用 PlantUML 绘制，并沿用现有 HTML 图像渲染。先识别本次涉及的用户、内部业务模块和外部系统边界；订单、商品等模块通常各占一列，不要求完成整个项目的领域划分。一个模块内的 Controller、Service、Mapper、DAO、任务及校验器合并，以业务动作表达必要内部处理。领域服务是图中业务职责的表达，不暗示独立部署。

数据库、下游和第三方按实际交互保留。异步或定时执行不自动拆出领域服务，不设硬性列数，不合并不同模块掩盖真实交互。保留业务分支、事务、异步、回调和补偿的必要语义。

方案 Spec 增加时序图标准，订单退款样例收敛为用户、订单服务、订单库、退款渠道，导出样例收敛为导出服务和导出任务库；执行说明继续保留具体实现约束。起草任务显式提供对应 Spec 节与样例路径，不新增独立图源或第二份审阅方案。

验证沿用规划契约及临时部署比对；真实图表渲染依赖本地 PlantUML 可用性。
