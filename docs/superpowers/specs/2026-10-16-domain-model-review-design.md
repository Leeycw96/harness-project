## 展示与源文档

数据库模型按订单域、商品域等领域分组，每域使用领域标题、表关系图和图下 SQL。图内列出字段、类型、中文注释、主键/关联键、必要约束及变化标记；已有表只列相关字段，新表列全设计字段，关系标明基数与逻辑关联/数据库外键。单表不补造关系。同域模型集中在一个所属功能定义，其他功能引用。

执行 MD 继续保留迁移、恢复及兼容约束，数据库模型 HTML 不展示这些说明。JSON 调整仍保留必要的结构表达；与关系图并存时使用独立 `### JSON结构` 小节。无迁移不补造 SQL。

SQL 在生成 HTML 时进行转义和语法着色，保留源文本及缩进，使用内嵌深浅主题样式，无额外依赖及网络请求。高亮只用于展示，不执行 SQL。

`data-model-example.html` 保存已确认的双领域版式，作为起草任务的参考。业务事实和数据库方言必须由 Planner 根据实际项目替换；正式审阅稿仍从 MD 渲染。

状态节点保留颜色和变化标记；连线标签只写动作或条件，不带新增、修改、删除标记，允许保留变化线色。
