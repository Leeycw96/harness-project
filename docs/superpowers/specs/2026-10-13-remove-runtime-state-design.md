# 移除运行状态台账

用户要求检查 `state.json` 的作用，作用较小时直接去掉；修改归入 4.0.5。

## 检查结论

阶段、前置检查、QA 状态、角色绑定与返修次数主要由主会话手工维护。完成助手只检查文件存在并打印，没有阶段机、自动限次或超时采集。用户进一步明确，删除整套运行管理功能，不转移到原会话或其他台账。

## 调整

- 删除运行状态、阶段和完成登记、确认留档、次数限制、超时恢复与历史状态兼容；删除通用助手和旧 shadow 汇总工具。
- Dev 初始化只验证并快照执行计划，返回 `run/plan.md`；保留 run 编号和计划文件防覆盖。
- Fix 脚本只验证和渲染修复说明，用户确认方案后安排修复，不另存批准记录。
- Plan 按反馈修订；Dev/Fix 按 QA 阻断项返修后再次验收，无固定次数或恢复协议。必要用户决策、方案确认与 QA 独立验收保留。
- 已有项目产物不做清理；新流程不读取或兼容历史运行状态。

## 验证

验证初始化只生成计划快照、拒绝覆盖、重新部署清理旧助手，继续运行 Agent/Spec 边界、Fix 渲染与资格、QA 评分、规划及指令精简契约。不把静态缩减当作实测提速。
